🍕 Pizza Sales Dashboard (Excel + SQL)

📌 Project Overview
This project analyzes pizza sales performance using SQL queries and presents insights through an interactive Excel Dashboard.

The dashboard helps understand:

* Revenue performance
* Order trends
* Best & worst-selling pizzas
* Category performance

🛠 Tools & Skills Used

Microsoft Excel

* Pivot Tables
* Charts and Dashboard Design
* KPI Cards
* Timeline

🧾SQL

* Aggregations (SUM, COUNT, AVG)
* GROUP BY, ORDER BY
* Trend analysis queries
  
📂 Dataset Information
* Records: 48,620 rows
* Columns: 14
* Key fields: order_date, order_time, pizza_category, pizza_size, quantity, total_price

📊 KPIs (Results)

* Total Revenue: 817,860.05
* Total Orders: 21,350
* Total Pizza Sold: 49,574
* Average Order Value: 38.31
* Average Pizza per Order: 2.32

🔍 Key Insights
* Highest order volume occurs on Friday
* Classic category contributes the highest revenue share
* Best-selling pizzas include:

  * The Classic Deluxe Pizza
  * The Barbecue Chicken Pizza
  * The Hawaiian Pizza
